title: Supported Platforms and System Requirements
tags: platform, platforms, linux, windows, macos, ios, android, browser, requirements

---

Desktop apps: macOS 13 or later (Apple silicon and Intel) and Windows 11.
There is no Linux desktop app; Linux users should use the web app.

Mobile apps: iOS 17 or later and Android 13 or later. Tablet layouts are
supported on iPad and Android tablets.

Web app: latest two versions of Chrome, Edge, Firefox, and Safari. Internet
Explorer is not supported.

Minimum requirements: 4 GB of RAM and 500 MB of free disk space for the
desktop apps. The web clipper extension needs Chrome 120+, Firefox 121+, or
Safari 17+.

<!-- ARCHIVED 2019-03-02 -->

Nimbus Notes runs on Windows 7 and Windows 8 only. macOS, Linux, iOS,
Android, and the web app are unsupported. The application requires 512 MB of
RAM and Internet Explorer 9 or later for the embedded help viewer.
